# Hasaki-Inspired Maison Belle Storefront Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the customer storefront easier to shop using a familiar ecommerce hierarchy while preserving Maison Belle's editorial luxury identity and existing API-backed interactions.

**Architecture:** Keep the current static HTML pages and shared CSS; align repeated storefront headers, refine layout styling for home/catalog/detail/cart, and preserve the existing `js/storefront.js` API behavior.

**Tech Stack:** HTML, CSS, vanilla JavaScript, current API adapter, Node.js test runner; no new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-09-hasaki-inspired-storefront-layout.md`

## Global Constraints

- Modify only customer HTML/CSS and presentation where needed; keep backend routes and API request/response shapes unchanged.
- Do not place `admin.html` in primary customer navigation.
- Do not invent ratings, bestseller rankings, shipping benefits, stock, sales counts, or dashboard metrics.
- Preserve demo labels, API-backed loading/error/empty/success states, and the existing reduced-motion behavior.
- Keep the layout responsive and accessible; add no dependency.
